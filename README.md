# Chai & Chapter Café – Django + MySQL SEO site

3-page site (Home, About, Blog) for a fictional Mumbai café. Blog posts and every page's meta title/description are stored in MySQL and loaded from there.

## Setup
```bash
python -m venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 1) create the MySQL database
mysql -u root -p -e "CREATE DATABASE chai_cafe_django CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2) set credentials (defaults: root, empty password, localhost)
export DB_NAME=chai_cafe_django DB_USER=root DB_PASS=yourpassword   # Windows: set VAR=value

# 3) tables + sample data
python manage.py migrate
python manage.py seed_cafe
python manage.py createsuperuser     # optional: edit posts at /admin/

python manage.py runserver
```
Open http://127.0.0.1:8000/. Quick try-out without MySQL: `DB_ENGINE=sqlite`.
Run checks: `python manage.py test` (heading order, unique meta, alt text, JSON-LD, sitemap, robots, 404).

Routes: `/`, `/about`, `/blog`, `/blog/<slug>`, `/sitemap.xml`, `/robots.txt`.

## SEO choices
- Unique `<title>`, meta description and canonical URL per page, read from MySQL (`Page` and `Post` models); Open Graph tags included.
- One `<h1>` per page with proper h1 → h2 → h3 order and semantic landmarks; verified by automated tests.
- Clean slug URLs without trailing slash (`/blog/best-chai-in-mumbai`); unknown slugs return a real 404 with `noindex`.
- `sitemap.xml` generated by `django.contrib.sitemaps` from the DB (with `lastmod`); `robots.txt` links to it. All images have alt text and width/height.
- Bonus: `CafeOrCoffeeShop` (LocalBusiness) JSON-LD on Home with address, geo and hours.

## Deploy (e.g. Render)
Build: `pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py seed_cafe`
Start: `gunicorn config.wsgi`
Env: `DEBUG=0`, `SECRET_KEY`, `ALLOWED_HOSTS=yourapp.onrender.com`, `CSRF_TRUSTED_ORIGINS=https://yourapp.onrender.com`, plus DB_* for a hosted MySQL.
